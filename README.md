# 标普500 成分股面板（stocks.weathertop.app）

[weathertop.app](https://weathertop.app) 主面板的子站：跟踪标普 500 全部成分股的
行情、市值权重与市场内部结构（Top10 集中度、上涨占比、板块宽度、52 周位置）。

## 架构

- **零逐股请求**：Nasdaq 批量筛选器一次调用获取全市场约 7000 行快照，本地过滤出
  成分股（名单来自 Wikipedia，缓存 7 天自动跟随指数调整）；
- **快照累积**：`data/snapshots/`（近 90 天每日 + 更早保留周五），集中度/宽度的
  历史序列由此生成，A/D 线与均线宽度类指标随累积逐步解锁；
- **慢速回填**：每次构建补 25 只成分股的十年日线（按市值从大到小，避开接口风控），
  约 3-4 周补齐全部，届时解锁"% 站上 50/200 日均线"等真实宽度指标；
- 每日两次自动构建（UTC 23:30 / 15:30），零第三方依赖（Python 标准库）。

## 本地运行

```bash
python3 build.py                       # 抓数 + 构建 public/data/stocks.json
python3 -m http.server 8968 -d public  # 本地预览
```
